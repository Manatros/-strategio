Drop PNG images here to texture the hex map, named exactly:

  grass.png
  stone.png
  water.png
  fields.png
  snow.png
  forest.png
  bridge.png
  highmountain.png

Any terrain kind without a matching file just keeps its current flat color
— you don't need to supply all of them at once. Images are masked to the
hex shape automatically, so square/rectangular source images work fine;
a roughly square, tileable-looking texture will look best. No specific
resolution is required — 128x128 to 256x256 is a reasonable range.
